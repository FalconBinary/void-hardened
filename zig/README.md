# zig — инструменты системы на Zig

Замена `src/` (C). Порт один к одному: те же аргументы, вывод и коды выхода;
каждая программа сверяется с C-версией дифференциальными тестами (`tests/zig/`).

```sh
cd zig && zig build -Dtarget=x86_64-linux --prefix КАТАЛОГ   # программы в КАТАЛОГ/bin
install/build-tools.sh /mnt                                   # [LIVE] сборка в RAM и установка
sh tests/zig/run.sh                                           # тесты в контейнере Void (docker)
```

Версия Zig закреплена: `ZIG_VERSION` (сейчас 0.17.0). Zig ломает совместимость
между релизами, поэтому сборка другой версией не поддерживается.

| Файл | Что |
|---|---|
| `lib/vh.zig` | общее: сообщения, системные вызовы, файлы, конфиги `KEY=VALUE`, запуск программ без шелла |
| `lib/hash.zig` | SHA-256 и BLAKE2b-512 (`std.crypto`) |

Правила кода:
- только системные вызовы Linux (`std.os.linux`), без `std.Io`: его API меняется от
  релиза к релизу;
- libc (glibc) — только там, где без неё нельзя (OpenSSL, libxcrypt, libxbps);
  остальные программы — статические PIE и не зависят от glibc системы;
- сборка в ReleaseSafe: проверки границ, переполнений и null остаются в программе;
- никакого шелла при запуске программ.
