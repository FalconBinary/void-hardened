# 12. Повседневная работа

> Модуль 12 промпта. Частые действия — без админа, через узкие механизмы; редкие и
> опасные — через админа на tty2.

## 1. Включение и вход

1. Limine (1 с) → пароль LUKS → tty1: вход `user` → сразу mango с панелью netline.
2. Админ: `Ctrl+Alt+F2` → вход `admin`. Назад к графике — `Ctrl+Alt+F1`.

## 2. Горячие клавиши (mango + void-hardened)

| Клавиши | Действие |
|---|---|
| `Super+Return` | терминал (foot) |
| `Super+D` / `Super+Shift+D` | zrun: приложения / команды |
| `Super+B` | браузер, доверенный профиль |
| `Super+Shift+B` | браузер, одноразовый профиль (для незнакомых сайтов) |
| `Super+W` / `Super+Shift+W` | меню Wi-Fi (zwifi) / Bluetooth (zbt) |
| `Super+P` | обои (zwall) |
| `Super+C` | календарь |
| `Super+Escape` | питание: блокировка, выход, перезагрузка, выключение |
| `Super+L` | **блокировка — «защищённая комбинация»** |
| `Super+F` | окно во весь экран (видео из браузера — только так) |
| `Super+U` / `Super+Shift+U` | флешка: подключить / отключить (модуль `optional/usb-auth`) |
| `Alt+1…9` / `Ctrl+1…9` | переместить окно на тег / перейти на тег (штатные mango) |
| `Alt+Q` | закрыть окно |
| яркость, громкость, микрофон | функциональные клавиши ноутбука |

Окна браузера открываются на **теге 9** и не забирают фокус: `Ctrl+9`, чтобы перейти.

**«Защищённая комбинация».** Увидели экран блокировки или запрос пароля, которого не
ждали? Нажмите `Super+L` перед вводом пароля. Привязку mango приложение отключить не
может (`allow_shortcuts_inhibit=0`) — настоящий swaylock ляжет поверх любого окна.

## 3. Сеть

- **Wi-Fi:** иконка на панели или `Super+W` — список сетей, подключение, «забыть».
  Пароль хранит iwd (`/var/lib/iwd`, только root). В терминале — `iwctl`.
- **Чужая сеть с порталом авторизации** (кафе, отель): подключитесь через zwifi,
  откройте одноразовый браузер (`Super+Shift+B`) и любой сайт по `http://` — портал
  перехватит запрос. Если портал в частной сети (`192.168.x.x`, `10.x.x.x`), файрвол не
  пускает туда браузер: админ на tty2 добавляет временное разрешение —
  `doas nft add element inet vh browser_lan '{ 10.0.0.1 . 80 timeout 10m }'` (адрес
  портала — шлюз: `ip route`).
- **Кабель:** просто подключите — dhcpcd поднимет адрес, трафик пойдёт по кабелю.
- **Bluetooth** (`VH_BLUETOOTH=optional`): переключатель в zbt (или правый клик по
  иконке) запускает сервис, второй раз — останавливает и блокирует радио.
  Из терминала: `doas /usr/local/sbin/vh-bluetooth on|off`.

## 4. Файлы

- Скачанное браузером — в `~/Downloads` (это `/home/xfer`). Файлы для отправки на
  сайт — тоже кладите туда: браузер видит только этот каталог.
- Перенесите нужное из `~/Downloads` в свои каталоги (`~/Documents` и т. д.) — браузер
  их не видит.
- Не открывайте подозрительные скачанные файлы обычными программами: PDF — сначала
  во встроенном просмотрщике браузера (одноразовый профиль), архивы и прочее —
  `optional/viewers` (песочница).
- Свои скрипты в `/home` не запускаются напрямую (`noexec`): `sh script.sh`,
  `python3 script.py` — да. Свои программы — в `~/dev` (если задан `VH_DEV_DIR`)
  или через админа в `/usr/local/bin`.

## 5. Флешки

В базовом слое флешку монтирует админ:

```sh
lsblk                                         # найти раздел, например sda1
doas mount -o nodev,nosuid,noexec,nosymfollow,uid=user,gid=user /dev/sda1 /mnt
# … работа …
doas umount /mnt
```

Монтирование без админа (по клавише, только mass storage, BadUSB-клавиатура не
оживает) — `optional/usb-auth` ([13](13-optional.md)).

## 6. Яркость, звук

- Яркость — клавишами (`vh-backlight ±5`); из терминала: `vh-backlight 40`.
- Звук — клавишами (`wpctl`); выход по умолчанию: `wpctl status`, `wpctl set-default ID`.

## 7. Выключение

`Super+Escape` → «Выключить» / «Перезагрузить» (через `doas` без пароля, только эти
команды без аргументов). Сна нет: ключ LUKS лежал бы в RAM (глава 05) — выключение и
быстрая загрузка вместо него.

Крышку и кнопку питания обслуживает root-демон `vh-acpid` (acpid не установлен — его
штатный обработчик усыпляет по крышке):

| Событие | Что происходит |
|---|---|
| крышка закрыта | экран сразу блокируется (swaylock) |
| крышка закрыта дольше 10 минут | штатное выключение — ноутбук в сумке не греется и не садится |
| подключён внешний монитор | крышка ничего не делает (работа с закрытой крышкой) |
| короткое нажатие кнопки питания | штатное выключение (сервисы остановлены, данные сброшены) |
| нажатие 4 с | аппаратное выключение мимо системы — только если всё зависло |

Пороги и поведение кнопки — `/etc/vh/acpi.conf` (через админа). Раскладка рабочих мест после включения — строки
`exec-once=` в `~/.config/mango/config.conf` (например, `exec-once=foot`).

## 8. Свои настройки

| Что | Где | Права |
|---|---|---|
| mango (клавиши, раскладки, внешний вид) | `~/.config/mango/config.conf` | ваш файл |
| foot | `~/.config/foot/foot.ini` | ваш файл |
| цвета netline | `~/.config/netline/theme` | ваш файл |
| защита mango (`/etc/vh/mango-vh.conf`) | через админа | root |
| политики браузера | через админа, `/etc/vh/firefox/` | root |
| правила файрвола | через админа, `/etc/nftables.conf` | root |

В параноидальном слое `optional/home-lockdown` конфиги становятся root-файлами
только для чтения, а правки идут через черновики и админа ([13](13-optional.md)).

## 9. Администрирование

На tty2 админом (`doas` спрашивает пароль каждый раз):

```sh
doas vh-update                 # обновления (глава 09)
doas vh-audit                  # проверка (глава 10)
doas vh-pkg add пакет          # поставить программу с проверкой (раздел 10)
doas svlogtail                 # журналы
doas -s                        # root-шелл (закроется через 10 минут бездействия)
```

После работы — `exit`: процессы админа завершаются все (`trap 'kill -KILL -1' EXIT`).

## 10. Установка программ: `vh-pkg`

У xbps нет хуков «после установки пакета», поэтому программы ставьте через обёртку
(админом на tty2):

```sh
doas vh-pkg add emacs              # показать, что потянется, установить, обезвредить
doas vh-pkg add emacs-pgtk --ignore gcc   # не ставить ненужную зависимость
doas vh-pkg rm emacs               # удалить вместе с ненужными больше зависимостями
doas vh-pkg scan ИМЯ               # разобрать уже установленный пакет
```

**До установки** — список всего, что потянется. Пакеты из чёрного списка (компиляторы,
polkit, elogind, avahi, cups, NetworkManager, Xwayland, cron, fuse…) помечены `!!` с
причиной; без подтверждения установка не идёт. Если нежелательное — зависимость, без
которой программа обходится, `--ignore` вписывает её в `ignorepkg`
(`/etc/xbps.d/51-vh-pkg-ignore.conf`). Убедитесь, что программа после этого работает.

**После установки** — разбор файлов каждого нового пакета:

| Что нашлось | Что делает vh-pkg | Почему |
|---|---|---|
| SUID/SGID, file capabilities | снимает; путь — в `/etc/vh/suid-strip.list` | точка повышения прав; `vh-suid-strip` снимет снова после обновления |
| `sysctl.d` | маскирует пустым одноимённым файлом в `/etc/sysctl.d` | файл пакета `99-*` применился бы после `30-vh-hardening` и перекрыл его |
| правило udev с `MODE 0666` | маскирует в `/etc/udev/rules.d` | устройство стало бы доступно всем |
| хук `/etc/kernel.d`, модуль dracut, скрипт `profile.d`/`bashrc.d` | `noextract` + удаление | исполняются от root при сборке UKI или в каждом шелле, в том числе у админа |
| сервис runit, D-Bus, автозапуск XDG, cron | только отчёт | Void сам сервисы не включает, активация D-Bus выключена, mango автозапуск не читает |

`vh-update` делает тот же разбор для обновлённых пакетов: обновление могло принести
новый SUID-файл или `sysctl.d`. Исключение для нужного файла: `--keep ПУТЬ`.

**Что не делается автоматически.** Удалить зависимость, которая программе нужна,
нельзя — xbps откажется, а принудительное удаление сломает программу. Поэтому выбор
делается **до** установки (`--ignore`), а «сироты» после удаления программ убирает
`xbps-remove -o` (vh-pkg вызывает его сам).

**Редакторы.** `emacs` (в терминале) тянет 13 библиотек без компилятора; `emacs-pgtk`
(окно Wayland) — `gcc` и `libgccjit` для нативной компиляции elisp (+584 МБ, и в системе
появляется компилятор). Варианты без компилятора: `neovim`, `helix`, `micro`. Файлы из
загрузок emacs может исполнить (file-local variables, org-babel) — в `init.el`:
`(setq enable-local-variables :safe enable-local-eval nil)`.

## 11. Сознательные ограничения удобства

| Ограничение | Почему |
|---|---|
| Нет сна и гибернации | ключ LUKS в RAM при сне; образ RAM на диске при гибернации |
| Админ — отдельный вход, пароль при каждом `doas` | скомпрометированный сеанс пользователя не повышает права |
| Пользователь не меняет свой пароль сам | `passwd` без SUID — меньше кода с правами root; меняет админ: `doas passwd user` |
| Браузер видит только ~/Downloads | RCE в браузере не читает ваши файлы |
| Окна браузера без автофокуса, на теге 9 | кража фокуса при вводе пароля |
| Одноразовый профиль ничего не помнит и медленный | эксплойты не закрепляются, без JIT меньше уязвимостей |
| Новое USB-железо другого типа — после `30-lock.sh` и перезагрузки | `modules_disabled` |
| Нет компилятора (кроме `VH_DEV_DIR`) | вредонос не соберёт инструмент на месте |
