# 11. Производительность: CPU, память, накопитель, графика, загрузка

> Модуль 11 промпта. Настройки этой главы **не ослабляют защиту**. Файлы:
> `/usr/local/sbin/vh-power` + `/etc/udev/rules.d/99-vh-power.rules`,
> `/etc/sysctl.d/50-vh-performance.conf`, `/etc/runit/core-services/05-vh-zram.sh`, `07-vh-mm.sh`,
> `/etc/sv/vh-fstrim`, `/etc/dracut.conf.d/10-vh.conf`.

## 1. Методика замеров

Каждую меру с ценой измеряйте **до и после**, при одинаковых условиях (питание от
сети, одинаковая температура, повтор 3–5 раз, медиана):

| Что | Как |
|---|---|
| Время загрузки | `dmesg \| head -1` (метка 0) … строка `runit: enter stage: /etc/runit/2`; от входа до mango — `/proc/uptime` в начале `vh-session` (временно добавить `cat /proc/uptime > /tmp/t`) |
| Время до запроса пароля LUKS | секундомер от кнопки питания (прошивка + Limine + распаковка UKI) |
| CPU и память | `zstd -b3 -T0 -i5 большой_файл` (многопоточно), `zstd -b19` (однопоточно) |
| Накопитель | `fio --name=r --filename=/home/user/fio.tmp --size=2G --rw=randread --bs=4k --iodepth=32 --ioengine=libaio --direct=1` (пакет `fio`, после замера удалить; не io_uring — он выключен sysctl) |
| Браузер | Speedometer 3 и JetStream в доверенном и одноразовом профиле |
| Видео | 1080p60 VP9 в доверенном профиле: загрузка CPU (`top`) и расход (`/sys/class/power_supply/BAT*/power_now`) |
| Батарея | `cat /sys/class/power_supply/BAT0/power_now` при простое 5 минут |

## 2. Профили питания без демонов

`vh-power` вызывается udev-правилом при подключении и отключении зарядки и один раз
при загрузке. Из события берётся только факт смены — состояние скрипт читает из
sysfs сам (событие могло бы прийти подделанным).

| | От сети | От батареи |
|---|---|---|
| EPP (`energy_performance_preference`) | `balance_performance` | `balance_power` |
| Runtime PM устройств PCI | выключен (`on`) — меньше задержки | включён (`auto`) |
| Энергосбережение Wi-Fi | выключено всегда (глава 07) | выключено всегда |

**Почему так, а не tlp/auto-cpufreq/power-profiles-daemon/thermald:** на CPU с HWP
частотой управляет сам процессор, ОС задаёт только предпочтение (EPP) — одна запись в
sysfs. Демоны — это root-процессы (часть — с D-Bus) ради этой записи. thermald имеет
смысл, только если `turbostat` (пакет есть) покажет троттлинг по температуре.

Проверка:
```sh
cat /sys/devices/system/cpu/cpufreq/policy0/{scaling_driver,energy_performance_preference}  # intel_pstate, …
cat /run/vh/power                                                                            # ac / battery
```

Хотите максимум от сети — `performance` вместо `balance_performance` в `vh-power`
(+5–10 % в коротких нагрузках, заметно больше тепла и шума).

## 3. CPU и планировщик

- `intel_pstate` в режиме active с HWP, turbo включён — ничего не трогаем.
- `preempt=full` (cmdline) — ядро вытесняется в любой точке: интерфейс и звук не
  дёргаются под фоновой нагрузкой. Цена — доли процента пропускной способности.
  Ядро Void собрано с `PREEMPT_VOLUNTARY` + `PREEMPT_DYNAMIC`: режимы переключаются
  параметром `preempt=` (`none`, `voluntary`, `full`), а `preempt=lazy` в этой сборке
  **нет** (`CONFIG_PREEMPT_LAZY` не задан — промпт его предлагал). Проверка:
  `cat /sys/kernel/debug/sched/preempt` недоступен (debugfs выключен) — смотрите
  `dmesg | grep -i 'dynamic preempt'`.
- Частота таймера — 1000 Гц (`CONFIG_HZ=1000`), как в CachyOS ([15](15-cachyos.md)).
- `kernel.sched_autogroup_enabled=1` — процессы одного терминала — одна группа
  планирования: `make -j12` в терминале не отнимает CPU у браузера.
- dGPU обесточена (глава 04) — меньше тепла, дольше турбо CPU.

## 4. Память

- **zram** (`05-vh-zram.sh`): zstd, 50 % RAM. lz4 быстрее сжимает, zstd плотнее
  (~3:1 против ~2:1). Для ноутбука с 8–16 ГБ — zstd: больше помещается, а цена сжатия
  на 6 ядрах незаметна. Проверка: `zramctl` (DATA / COMPR — степень сжатия).
- `vm.swappiness=180`, `vm.page-cluster=0` — глава 05.
- `vm.watermark_boost_factor=0`, `vm.watermark_scale_factor=125` — kswapd освобождает
  память заранее и плавно, без рывков при всплесках (открыли десяток вкладок).
- `vm.vfs_cache_pressure=50` — кэш имён файлов и inode живёт дольше (быстрее `git
  status`, поиск, сборка). Как в CachyOS.
- `vm.dirty_background_bytes=64M`, `vm.dirty_bytes=256M` — фоновая запись начинается
  с 64 МБ несброшенных данных, процесс-писатель притормаживается на 256 МБ. По
  умолчанию пороги — проценты RAM (10 % и 20 %, то есть 0,8 и 1,6 ГБ на 8 ГБ): копия на
  медленную флешку набивала бы гигабайты грязных страниц, а `sync` и отмонтирование
  «замирали» бы на минуты. Заодно в RAM меньше открытого текста недавно записанных
  файлов (модель угроз, [05](05-system.md)). Как в CachyOS.
- **MGLRU** (многопоколенческий LRU) в ядре Void включён при сборке
  (`CONFIG_LRU_GEN_ENABLED=y`; проверка: `cat /sys/kernel/mm/lru_gen/enabled` → `0x0007`)
  — лучше выбирает, что вытеснять.
- **THP** (прозрачные огромные страницы): `madvise` — получают программы, которые
  просят (Firefox, mesa); это умолчание ядра Void. `07-vh-mm.sh` ставит
  `defrag=defer+madvise`: уплотнение памяти под них идёт в фоне, а не в момент page
  fault — нет задержек. Проверка: `cat /sys/kernel/mm/transparent_hugepage/{enabled,defrag}`.
- `init_on_free=1` — цена по замеру (fio, Speedometer); по умолчанию оставляем:
  открытый текст в освобождённой памяти — цель атаки холодной загрузки.

## 5. Накопитель

- Планировщик NVMe — `none` (по умолчанию): у NVMe свои очереди, планировщик ядра
  только мешает. Проверка: `cat /sys/block/nvme0n1/queue/scheduler`.
- dm-crypt без workqueue (глава 01), XFS `noatime,logbsize=256k`.
- TRIM — сервис `vh-fstrim` раз в неделю с `ionice -c3` (самый низкий приоритет
  ввода-вывода), без cron и snooze.
- `iommu.strict=1` — цена на NVMe с высоким IOPS: замер `fio` 4K QD32 с ним и без
  (`VH_EXTRA_CMDLINE=iommu.strict=0` на одну загрузку — и обратно). По умолчанию
  оставляем: защита от DMA скомпрометированной прошивки Wi-Fi или NVMe.
- APST (энергосбережение NVMe) — по умолчанию. Если накопитель «отваливается» под
  нагрузкой — `nvme_core.default_ps_max_latency_us=0` в `VH_EXTRA_CMDLINE`.

## 6. Графика и видео

- mango на iGPU; VA-API в доверенном профиле браузера (VP9/H.264/HEVC — GPU, AV1
  выключен — глава 04). Проверка: `about:support` → «Media» → «Hardware decoding».
- Одноразовый профиль браузера — программная отрисовка и без JIT: сознательная цена
  (замер Speedometer 3: обычно в разы ниже доверенного).
- В mango: `blur=0`, `shadows=0` (по умолчанию в пакете) — минимум работы GPU;
  анимации — по вкусу (`animations=0` — мгновенное переключение).

## 7. Загрузка

| Этап | Что ускоряет | Цена |
|---|---|---|
| Прошивка | Fast Boot выключен (глава 00) — секунда-две | ради стабильной клавиатуры и PCR |
| Limine | `VH_LIMINE_TIMEOUT=1` (0 — без меню) | меню выбора ядра |
| UKI | hostonly, только нужные модули, без plymouth; `lz4` распаковывается быстрее `zstd`, `zstd` меньше читать — замерьте оба | — |
| Пароль LUKS | Argon2id ~3 с — **не снижать** (запрещённое ускорение) | 3 с |
| Стадия 1 | nftables одним `nft -f`; AppArmor — только 5 профилей и из кэша; sysctl одним проходом | — |
| Стадия 2 | все сервисы параллельно; iwd без пересоздания интерфейса; сеть готова к моменту входа | — |

Цель — меньше минуты от кнопки до рабочего стола вместе с вводом паролей.

## 8. Запрещённые ускорения

| «Ускорение» | Выигрыш | Что открывает |
|---|---|---|
| `mitigations=off`, `spectre_v2=off`, `gather_data_sampling=off`, `retbleed=off`, `mmio_stale_data=off`, `indirect_target_selection=off` | 2–15 % в системных вызовах и AVX | чтение памяти ядра и других процессов из JS и песочниц |
| `intel_iommu=off`, `iommu=pt`, `iommu.passthrough=1` | единицы % на NVMe | DMA-атаки устройств и их прошивок |
| Отказ от `init_on_free`, `slab_nomerge`, `page_alloc.shuffle` без замера | ~1–5 % | открытый текст в свободной памяти; проще эксплойты кучи |
| `nowatchdog`, `kernel.nmi_watchdog=0` | доли % | ломает перезагрузку при зависании (`hardlockup_panic`): ключ остаётся в RAM |
| андервольт (`intel-undervolt`) | ниже температура, дольше турбо | нужна запись в MSR из userspace — её запрещает lockdown; снимать lockdown нельзя ([15](15-cachyos.md)) |
| suspend / гибернация вместо выключения | мгновенный старт | ключ LUKS в RAM (suspend) или на диске (гибернация) |
| Слабее Argon2id | 1–2 с | перебор пароля дешевле в разы |
| Без seccomp/AppArmor/bwrap у браузера, JIT и WebGL в одноразовом профиле | скорость JS | RCE браузера = доступ ко всему сеансу |
| Xwayland, sched_ext, BPF LSM | совместимость, «умные» планировщики | X11 без изоляции; root-код в ядре |
| Демоны «ускорители» (preload, irqbalance) | доли процента | лишние root-процессы |
